# 🎫 HapDesk - Sistema de Help Desk

Sistema de gerenciamento de chamados e solicitações com aprovação em tempo real utilizando Firebase.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- Firebase Firestore
- Firebase Hosting

## 📋 Funcionalidades

- Abertura de chamados
- Aprovação de solicitações
- Chat de suporte
- Atualização em tempo real
- Painel administrativo

## 👥 Perfis

### Usuário

- Abrir solicitações
- Acompanhar status
- Conversar com suporte

### Administrador

- Aprovar solicitações
- Gerenciar usuários
- Acompanhar chamados

## 🏗️ Estrutura

/
├── index.html
├── usuario.html
├── admin-login.html
├── painel.html
├── firestore.rules
└── firebase.json

## 🔥 Firebase

O projeto utiliza:

- Authentication
- Firestore Database
- Hosting

## ⚙️ Deploy

firebase login

firebase init

firebase deploy

## 🎯 Objetivo

Automatizar o fluxo de atendimento e aprovação de acessos dentro de uma organização.
